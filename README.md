# NRI_LAND

Landing page for **Vensura Care**, a parent-care concierge for NRI families, by Abburi Pvt Ltd.

One trusted person on the ground in India: regular visits, doctor and hospital coordination, emergency response and video updates for your parents. Yearly membership in USD.

- Stack: HTML + CSS only, no build step
- Hosting: Vercel (static)
- Leads: waitlist form via Web3Forms, plus WhatsApp chat button
